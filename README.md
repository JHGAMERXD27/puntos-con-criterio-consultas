# Puntos con criterio - consultas

Canal público para correcciones y consultas editoriales de https://robuxfreerewards.vercel.app.

Abre una consulta en Issues e indica el artículo y lo que debe revisarse. No publiques contraseñas, correos privados, teléfonos, códigos de recompensas, capturas de cuentas ni datos de pedidos.

Este proyecto es independiente de Microsoft. No podemos gestionar cuentas, revisar saldos ni recuperar recompensas. Utiliza el soporte oficial para esas cuestiones. No se garantiza un plazo de respuesta.
